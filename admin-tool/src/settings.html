⚙️ Paramètres

Ces paramètres permettent à l'outil d'administration de publier automatiquement les quiz sur GitHub Pages via l'API Git.
Le fichier settings.json est stocké localement dans le dossier admin-tool/ et n'est jamais versionné.
Votre nom d'utilisateur GitHub (pas l'e-mail).
Le chemin complet du dépôt, ex : alakin66/french-quiz-app.
Requis pour les dépôts privés ou pour pousser sans configurer SSH. Le token doit avoir la permission repo (ou public_repo pour un dépôt public).
🔗 Créer un token sur GitHub
